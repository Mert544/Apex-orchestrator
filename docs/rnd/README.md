# Apex — Faaliyet-Öncesi Ar-Ge Paketi

Bu klasör, Apex Orchestrator için **dengeli** (yatırımcı cazibesi + dürüst iç strateji) bir
faaliyet-öncesi Ar-Ge çalışmasıdır: rakip analizi, pazar konumu, yatırımcı tezi, geliştirme
yönleri ve kör taraflar.

## İçerik

| Dosya | Nedir | Nasıl açılır |
|---|---|---|
| **`apex-arge-sunum.html`** | Tek-dosya, **çevrimdışı**, 22-bölümlük Türkçe sunum deck'i | Tarayıcıda aç (çift tıkla). `← →` ile gez · sol menüden bölüme atla · `☀︎/☾` tema · **Print → PDF** ile deck PDF'i |
| **`APEX-ARGE.md`** | Aynı içeriğin uzun-form Türkçe Ar-Ge dokümanı (22 bölüm + matrisler) | Markdown görüntüleyici / GitHub |

## Kapsam (22 bölüm)
Ürün & MOAT & Kanıt → Rekabet (iki kamp, 14-boyut matris, en-yakın rakipler) → Pazar (büyüklük,
LLM maliyet krizi, regülasyon, fonlama) → Yatırımcı tezi (A–E) & iş modelleri → SWOT, riskler & kör
noktalar → North-Star hizalı geliştirme yönleri & exit tezi.

## Notlar
- **Self-contained:** HTML hiçbir harici kaynağa (CDN/font/görsel) bağlı değildir — ağ kapalıyken çalışır.
- **Sayılar:** Apex'e dair iç iddialar bu depodan; rakip/pazar verileri kamuya açık kategori bilgisidir (~2026 web araştırması) — yönlendirme, denetim değil.
- **Çerçeve:** dengeli — her cazibe yönüne eşlik eden dürüst bir sınır/risk vardır.
