Why Apex?

LLM review tools cost money on every PR and answer differently every run. Apex's core is a deterministic reasoning engine — it's free to run forever, reproducible in CI, and your code never leaves the machine.

🔒

Finds what matters

One canonical AST detector: eval/exec, shell & SQL injection, unsafe pickle/yaml, weak hashes, swallowed exceptions, logic bugs like x is 5 — with inline # noqa/# nosec respected.

🧪

Fixes are proven

Every auto-fix is applied in a sandbox, verified against your test suite, and rolled back automatically if anything breaks. A maintenance run can never leave the project broken.

💡

Ideas, not just issues

The Idea Permutation Engine proposes how to develop the project — down to the function: “write behavioral tests for _expand() (complexity 23, never named by a test)”.

🎓

One honest grade

Security · Architecture · Testing · Code debt · Correctness — severity-weighted, fixture-aware, and shallow stub tests only get half credit. An A+ can't be faked.

Gate your PRs — free, in 2 minutes

A drop-in GitHub Action: grade the project and review the diff on every pull request. Deterministic, so the gate is fast and reproducible.

# .github/workflows/apex.yml
name: Apex health gate
on: [pull_request]
jobs:
  apex:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: Mert544/Apex-orchestrator@v1
        with:
          min-score: "80"          # fail the PR if the grade drops below 80
          base: origin/${{ github.base_ref }}
          fail-on-high: "true"   # fail on a high-severity issue in the diff
